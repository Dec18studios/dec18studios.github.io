Quick Start · Technicolor DRT

From flat scan to dye-transfer print in five steps.

This guide gets you to a great Technicolor look fast using Single Stock (Modern), the default mode, then shows you when to reach for the classic two-strip and three-strip processes.

Start installing → Jump to the workflow

Step 1 · Install & apply

Get it onto a node.

Install through the Tool Box Manager, then feed the plugin the right input. Three quick moves.

Install via the Tool Box Manager

Grab the Tool Box Manager, pick Technicolor DRT, click Install, then restart Resolve (enable OFX; on macOS choose Allow Anyway in Privacy & Security). Windows & Linux need a Turing-class NVIDIA GPU or newer.

Apply it to a serial node

Add a serial node and apply Technicolor DRT from the OFX Effects library. It lives in Resolve's OFX group Dec18studios.

Feed it the right input

Set Input Mode to DaVinci Intermediate if your timeline is DWG/Intermediate, or Linear if you've already converted. In doubt, add a Color Space Transform to DaVinci Wide Gamut / Intermediate with no tone mapping just before the node.

Step 2 · The 60-second workflow

Your first look, in five moves.

Every step here is a real control. Stay in Single Stock (Modern) and work top to bottom.

Leave Processing Method on Single Stock (Modern)

It's the default, and the most flexible, forgiving Technicolor look. Don't change it yet.

Load a Full Preset

A Full Preset loads a complete stock (silver sensitivity, dye formation and HD curves) at once. Start with a balanced neutral preset.

Turn on Auto Anchor Registers

In the Register Extraction group, switch on Auto Anchor Registers. It measures your black and white points from the stock automatically.

Set exposure with the Printer Lights

Use the lights, not the curves. Lower Printer Light to print brighter, raise it to print denser. Trim Red / Green / Blue Printer Points to balance color (25 = neutral; ±1 ≈ 1/12 stop).

Pick a Projector Bulb

Carbon Arc for a vintage house look, White Flame for a brighter arc, Xenon for a clean modern source.

Dial order that works

Drop the Register Black Points until scene black just hits full density, set the White Points, set Gel Matrix Gamma for contrast, then use the Printer Lights for exposure and balance only.

Step 3 · The modes in plain language

When to reach for each mode.

Four processing methods sit in one dropdown. Start with the first, and treat the rest as deliberate choices.

Start here

Single Stock (Modern)

The flexible modern Technicolor look.

Use it for almost everything. It gives you the dye-transfer richness with clean, controllable registers, and it's the most forgiving way into the tool.

When to use

Almost every shot. This is your default and your starting point.

Diagnostic

Neg Scan

A clean developed-negative view.

The developed negative on its own, before any dye-transfer print. Use it to tune the negative stock and texture before you commit to a print look.

When to use

Tuning the stock, or as a clean reference.

2-Strip

Process 3

The real two-strip look: teal-and-rose, no blue.

Reach for it when you want an early-talkies or silent-era period feel. Recommended stock: Double-X 5222 as the Neg Sensitivity preset.

When to use

A specific, romantic two-strip period look.

3-Strip

Process 4

Deep, saturated, dimensional: the glory era.

The real three-strip look. Use the Gold Mirror Bias slider to balance the prism. It's heavier-duty, so expect to spend more time balancing.

When to use

A full three-strip look, when you have time to balance it. In doubt, return to Single Stock (Modern).

Step 4 · Get the most out of it

Five habits that pay off.

Small workflow choices that keep the panel predictable and the look authentic.

Tip 01

Balance with registers, expose with lights

Set black and white points in Register Extraction first, then use Printer Lights purely for exposure and color balance. The two stages do different jobs, so don't fight one with the other.

Tip 02

Use the Gel Matrix masters for global moves

Gel Matrix DMin / White / Gamma move all three registers together. Deepen the matrix, clean the whites, or shift contrast there instead of tweaking three registers by hand.

Tip 03

Design the dyes in the Dye Designer

Open Dye Designer… to set the C / M / Y / K dye hues and watch each plate land on its own with live thumbnails. Tune Max Density and Green Flash in the header. Start from the Gentle Pull shaping preset.

Tip 04

Sculpt the stock in the Film Stock Editor

Open Textures Editor… to draw silver sensitivity, dye absorption and HD curves on the 43-band graph, and to set Grain / Halation / MTF. Your hand-drawn curves override the measured and Gaussian fallbacks.

Tip 05

Projector bulbs change the feel for free

Try Carbon Arc vs Xenon before reaching for any other control. The bulb is the cheapest, most authentic mood swing in the panel. (Editing a trim by hand flips the preset to Custom.)

Step 5 · Troubleshooting

Common snags, fixed fast.

The quick answers to the things that trip people up first.

The image looks washed out or low-contrast
  1. Your registers aren't anchored. Turn on Auto Anchor Registers, or lower the Register Black Points until scene black reaches full density.
Colors look off, or there's a cast
  1. Balance with the Red / Green / Blue Printer Points (25 = neutral), and use Gel Matrix White to clean residual dye out of the whites.
It's too dark or too bright
  1. Adjust Printer Light. Remember the lab convention: more light = denser, darker print, so lower it to print brighter.
I picked a bulb preset but it switched to "Custom"
  1. Editing any projector trim or Power by hand flips the preset to Custom. That's expected. Reselect a bulb to snap back.
The Dye Designer or Film Stock Editor won't open on Windows or Linux
  1. Both panels run on all platforms in v12, but Windows and Linux require a Turing-class NVIDIA GPU or newer. On macOS, make sure Resolve has been allowed in Privacy & Security.
Two-strip or three-strip looks wrong
  1. Process 3 and Process 4 are specialized. For Process 3, use Double-X 5222 as the Neg Sensitivity preset. For Process 4, balance the prism with Gold Mirror Bias before judging the look. When in doubt, return to Single Stock (Modern).
Which input should I feed it?
  1. DaVinci Intermediate (DWG/Intermediate timeline) or Linear, set via Input Mode. Add a no-tone-map CST before the node if needed.
