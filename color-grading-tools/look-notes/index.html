Which look
is this?

The frame tells the client, so you don't have to.

Look Notes burns a label and a couple of lines of notes right into the picture, for up to eight looks. Pitching looks in a client session? Change the Active Look and the frame says which one is up and what it is. On Resolve Studio it also flips your look nodes for you, so one control swaps the grade and the label together.

How it works

Three steps, then one control.

Set it up once before the session. After that you only touch Active Look.

Step 01

Label your nodes

In the node graph, give each look node a label that matches the look's label in the plugin, like Warm or Cool. Or just call them Look 1, Look 2 and so on. Case doesn't matter. Nodes with no look label are never touched.
Step 02

Fill in labels and notes

Drop Look Notes on a node. Each of Look 1 to Look 8 has its own Label and Notes field. Type what the client should read: the look's name, then a line or two on what it's doing.
Step 03

Change Active Look

Pick a look. The burned in panel updates, the matching nodes turn on and the other looks' nodes turn off. If no node matches the look you picked, nothing gets turned off, so a typo never blanks the grade.

Toggling only happens when you change Active Look by hand. Opening a project, undo, copying grades and switching versions never flip nodes. If you keyframe Active Look, the notes follow the keyframes but the nodes stay put. Stuck? The How To Set Up... button in the plugin opens a plain text step by step guide.

Split looks

Every matching node flips together.

Look Notes works on nodes in the clip graph and at the Timeline level. Every node with a matching label switches at once, so a look doesn't have to live in one node.

Say you run a shared base, then a shot level adjustment, then the look branches just before a mixer. Label the last node of each look branch and the whole split look flips in one go.

  • Base and shot nodes have no look label, so they always stay on.
  • Warm branch labelled Warm, on when Warm is the Active Look.
  • Cool branch labelled Cool, off until you pick Cool.

Switch Active Look to Cool and the two branch nodes trade places. Base and Shot carry no look label, so they are never touched.

PowerGrade Mode draws the label only, as large as it fits, dead centre. Grab a still and the thumbnail tells you which look it holds.

PowerGrades

Stills that name themselves.

A Gallery full of near identical thumbnails is no fun. PowerGrade Mode fixes that: big label, centre of frame, nothing else.

The trick is where you put things. PowerGrades and DRX stills only save clip node layer 1. So build your look chain on layer 1, and put Look Notes on the Timeline graph or on clip layer 2 in PowerGrade Mode.

The still thumbnail shows the label, but the saved grade does not carry the Look Notes node. Clean grade, labelled thumbnail.

How To Set Up...

Opens a plain text step by step guide to setting up node toggling.

Layout
Burn In

Off passes the image through untouched.

Position

Bottom, Top or Center. Plus PowerGrade Mode: label only, as large as fits, dead centre.

Show

Label and Notes, Label Only, or Notes Only.

Align

Left, centre or right.

Text size, opacity, brightness

Size the text and set how strong the panel sits on the image.

Label and notes colour

Separate colours for the label and the notes.

Reframe and palette
Reframe

Tick it at the top of the panel, then pick Bottom Strip or Side Panel. The picture shrinks to fit, keeps its shape, and the notes get their own panel instead of sitting on the image.

Panel Size and Background

How much of the frame the panel takes (10 to 50 percent) and what colour fills it.

Palette

3 to 12 colour swatches pulled from the image, sorted by hue, dominance or brightness. Skip near blacks, near whites and greys if you want only the real colours.

Fonts
Garamond

System Garamond on macOS, Office Garamond on Windows when installed, and EB Garamond bundled for everything else, so it always has a Garamond.

Pixel

A built in bitmap font. Always there.

Custom

Pick your own two font files: one for the label, one for the notes.

Requirements and platforms

What you need for node toggling.

The burn in works anywhere the plugin loads. Flipping nodes needs a little setup.

DaVinci Resolve Studio

Node toggling needs the Studio version of Resolve.

Turn on local scripting

Go to Preferences > System > General and set External scripting using to Local. Restart Resolve after.

Have Python 3

Toggling runs Resolve's Python scripting on macOS, Windows and Linux. Mac and Linux usually have it. On Windows grab the installer from python.org.

Runs on the GPU

Metal on macOS (universal, Intel and Apple silicon), CUDA on Windows and Linux, with a CPU fallback. The text panel is drawn once and cached, so it costs next to nothing per frame.

Safe by design

Nodes with no look label are never touched. If no node matches the chosen look, nothing gets turned off. Project loads, undo, grade copies and version switches never flip anything.

Getting started

Install in a couple of steps.

Look Notes is a standard OFX bundle. Drop it in your OFX plugins folder and restart. Or let the Tool Box Manager install it in one click along with everything else.

Download your platform build

Grab the macOS, Windows or Linux build from the Downloads above, then unzip the .zip.

Move it into your OFX plugins folder

macOS: /Library/OFX/Plugins · Windows: C:\Program Files\Common Files\OFX\Plugins · Linux: /usr/OFX/Plugins. The final layout is /OFX/Plugins/LookNotes.ofx.bundle/.

Restart Resolve

Relaunch so Resolve picks up the new plugin. If you want node toggling, set External scripting using to Local first, so one restart covers both.

Drop it on a node and label your looks

Find Look Notes under the Dec. 18 Studios OFX group. Fill in your labels and notes, label your look nodes, then change Active Look.

Heads up · macOS Gatekeeper

On macOS, if Apple tells you to delete it, don't. Open System Settings → Privacy & Security, choose Allow Anyway for Look Notes, then restart Resolve. The plugin is unsigned, not unsafe.
