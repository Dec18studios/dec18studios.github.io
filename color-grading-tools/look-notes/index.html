How it works

Three steps, then one control.

Set it up once before the session. After that you only touch Active Look. This part works the same in Pro and Lite.

Step 01

Label your nodes

In the node graph, give each look node a label that matches the look's label in the plugin, like Warm or Cool. Or just call them Look 1, Look 2 and so on. Case doesn't matter. Nodes with no look label are never touched.
Step 02

Fill in labels and notes

Drop Look Notes on a node. Every look has its own Label (the title line) and multi line Notes, plus there's one shared Header line on top. Pro gives you Look 1 to Look 8, Lite gives you Look 1 to Look 3. Type what the client should read: the look's name, then a line or two on what it's doing.
Step 03

Change Active Look

Pick a look. The burned in panel updates, the matching nodes turn on and the other looks' nodes turn off. If no node matches the look you picked, nothing gets turned off, so a typo never blanks the grade.

Toggling only happens when you change Active Look by hand. Opening a project, undo, copying grades and switching versions never flip nodes. If you keyframe Active Look, the notes follow the keyframes but the nodes stay put. Stuck? The How To Set Up... button in the plugin opens a plain text step by step guide.

Split looks

Every matching node flips together.

Look Notes works on nodes in the clip graph and at the Timeline level. Every node with a matching label switches at once, so a look doesn't have to live in one node.

Say you run a shared base, then a shot level adjustment, then the look branches just before a mixer. Label the last node of each look branch and the whole split look flips in one go.

  • Base and shot nodes have no look label, so they always stay on.
  • Warm branch labelled Warm, on when Warm is the Active Look.
  • Cool branch labelled Cool, off until you pick Cool.

Switch Active Look to Cool and the two branch nodes trade places. Base and Shot carry no look label, so they are never touched.

New in 1.2 · Export

Every look, saved for the client.

The session's over and the client wants to sleep on it. Hit Export All Looks, pick a folder, and Look Notes switches to each look in turn and saves a still of the current frame for each one, named with the look's Label and today's date. Then it puts your original look back.

Turn on Build Grid and it also saves a Look Grid: every look side by side in one image, up to 3840 wide. One attachment, all the options. The folder pops open when it's done.

  • Export All Looks and the Look Grid are Pro.
  • Export Current Look is in both. Lite saves JPG, Pro saves PNG, JPG or TIFF.

Export Current Look

Still Format

PNG, JPG or TIFF

PNG is 8 bit lossless, JPG is small and ready to share, TIFF is 16 bit. The Look Grid isn't available with JPG. Lite saves JPG, Pro picks any of the three.

Export runs through Resolve's scripting, same as node toggling, so it needs Resolve Studio with External scripting using set to Local, plus Python 3. See Requirements.

PowerGrade Mode draws the label only, as large as it fits, dead centre. Grab a still and the thumbnail tells you which look it holds.

PowerGradesPro

Stills that name themselves.

A Gallery full of near identical thumbnails is no fun. PowerGrade Mode fixes that: just the look's name, big and centred, nothing else. Handy when you're building a PowerGrade library.

The trick is where you put things. PowerGrades and DRX stills only save clip node layer 1. So build your look chain on layer 1, and put Look Notes on the Timeline graph or on clip layer 2 in PowerGrade Mode.

The still thumbnail shows the label, but the saved grade does not carry the Look Notes node. Clean grade, labelled thumbnail.

Requirements and platforms

What you need for node toggling and export.

The burn in works anywhere the plugin loads. Flipping nodes and exporting stills need a little setup.

DaVinci Resolve Studio

Node toggling and export need the Studio version of Resolve.

Turn on local scripting

Go to Preferences > System > General and set External scripting using to Local. Restart Resolve after.

Have Python 3

Toggling and export run Resolve's Python scripting on macOS, Windows and Linux. Mac and Linux usually have it. On Windows grab the installer from python.org.

Runs on the GPU

Metal on macOS (universal, Intel and Apple silicon), CUDA on Windows and Linux, with a CPU fallback. The text panel is drawn once and cached, so it costs next to nothing per frame.

Safe by design

Nodes with no look label are never touched. If no node matches the chosen look, nothing gets turned off. Project loads, undo, grade copies and version switches never flip anything.
